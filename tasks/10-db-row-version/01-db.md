## TDDAB-1: Let the database generate the row version, and warn that SQLite has none

<intro>
The lock's version moves from the application to the database. An entity declares EF's `[Timestamp]` on
a `uint` (PostgreSQL: Npgsql maps it to `xmin`); `ApplyOptimisticLock` takes the context's `Database` and
shapes the row versions: on SQLite each gets the default value 0 (the INSERT fails without it) and one
warning goes to the application's logger; a row version that is not `uint`/`ulong`/`long` is refused, and
on PostgreSQL only `uint`. Nothing of ours writes the version: EF reads back what the database generated.

```csharp
// src/Zerox.Ef/Db/ModelBuilderExtensions.cs
using System.ComponentModel.DataAnnotations;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Infrastructure;
using Microsoft.EntityFrameworkCore.Metadata;
using Microsoft.Extensions.Logging;
using Zerox.Ef.Core;

namespace Zerox.Ef.Db;

/// <summary>
/// The library's part of a context's model.
/// </summary>
public static class ModelBuilderExtensions
{
    private const string SqliteProvider = "Microsoft.EntityFrameworkCore.Sqlite";
    private const string PostgresProvider = "Npgsql.EntityFrameworkCore.PostgreSQL";
    private static readonly Type[] NumericRowVersions = [typeof(uint), typeof(ulong), typeof(long)];

    /// <summary>
    /// Shapes the optimistic lock. Call it at the END of OnModelCreating with the context's Database. An
    /// entity opts in with EF's [Timestamp] on a property of the type its database generates — uint on
    /// PostgreSQL (the system column xmin), ulong or long on SQL Server (rowversion): the database writes it,
    /// EF reads it back, nothing of ours sets it. Any other type is refused (NotSupportedException). SQLite
    /// generates no row version: there each gets the default 0 and one warning says the lock is off.
    /// </summary>
    public static ModelBuilder ApplyOptimisticLock(this ModelBuilder modelBuilder, DatabaseFacade database)
    {
        ArgumentNullException.ThrowIfNull(modelBuilder);
        ArgumentNullException.ThrowIfNull(database);

        // The app-managed lock of IHasOptimisticLock, until block 05 removes it.
        foreach (var type in modelBuilder.Model.GetEntityTypes()
                     .Where(t => typeof(IHasOptimisticLock).IsAssignableFrom(t.ClrType)))
            modelBuilder.Entity(type.ClrType).Property(nameof(IHasOptimisticLock.Version)).IsConcurrencyToken();

        var rowVersions = RowVersions(modelBuilder.Model).ToList();
        foreach (var property in rowVersions)
            Check(property, database.ProviderName);

        if (rowVersions.Count > 0 && database.ProviderName == SqliteProvider)
        {
            foreach (var property in rowVersions)
                property.SetDefaultValue(Activator.CreateInstance(property.ClrType));
            database.GetService<ILoggerFactory>().CreateLogger("Zerox.Ef.Db").LogWarning(
                "SQLite generates no row version: the optimistic lock of {Entities} is off, every save goes through.",
                string.Join(", ", rowVersions.Select(p => p.DeclaringType.ClrType.Name).Distinct()));
        }
        return modelBuilder;
    }

    // A row version as EF defines it (IsRowVersion, [Timestamp]): a concurrency token generated on add and update.
    private static IEnumerable<IMutableProperty> RowVersions(IMutableModel model) =>
        model.GetEntityTypes().SelectMany(t => t.GetDeclaredProperties())
            .Where(p => p.IsConcurrencyToken && p.ValueGenerated == ValueGenerated.OnAddOrUpdate);

    private static void Check(IMutableProperty property, string? provider)
    {
        var name = $"{property.DeclaringType.ClrType.Name}.{property.Name}";
        if (!NumericRowVersions.Contains(property.ClrType))
            throw new NotSupportedException(
                $"{name}: a row version travels to the client as a number — uint on PostgreSQL, ulong on SQL Server — not {property.ClrType.Name}.");
        if (provider == PostgresProvider && property.ClrType != typeof(uint))
            throw new NotSupportedException($"{name}: on PostgreSQL the row version is a uint (the system column xmin).");
    }
}

## TDDAB-2: Save and delete a client's row at the version it read, without reading it first

<intro>
Depends on 01 (`Locked` with `[Timestamp] uint Version`; row version = `IsConcurrencyToken` and
`ValueGenerated.OnAddOrUpdate`). `IRepository<T>` gets the three members the API will use (block 04):

- `void Update(T entity, IReadOnlyCollection<string> fields)` — the entity as the client sent it, not
  tracked: attached, and only `fields` marked modified. A name that is the key or a property the database
  generates (the row version) is never written; a name the entity does not have is an `ArgumentException`.
  The entity's row version is the one the client read: EF puts it in the `WHERE`.
- `bool TryDeleteById(int id, ulong? versionReadByClient)` — marks to delete a stub `T` with that Id
  (created with `Activator.CreateInstance<T>()`: the entity needs a parameterless constructor, as its `///`
  says) carrying, when the entity has a row version, that version in the row version's type; returns true.
  A version that does not fit the type is the CLIENT's mistake, an expected failure: false, nothing marked
  (CLAUDE.md P9: a Try-pattern, not an exception). Without the version on an entity that has one:
  `ArgumentException` (misuse — the caller checks `HasRowVersion` first). Ignored for an entity without a
  row version.
- `bool HasRowVersion { get; }` — whether the entity has a row version.

A missing row and a stale version both fail the next save with `DbUpdateConcurrencyException` (EF expects 1
row); telling them apart is the API's (block 04). `PinReadVersion` stays until block 05.

Files: `src/Zerox.Ef/Core/IRepository.cs` (the three members, `///`; the summary of `GetByIdAsync` loses its

// src/Zerox.Ef/Core/IRepository.cs — the new members
/// <summary>
/// The entity as the client sent it, not tracked: attached, written by the next save, only the named
/// fields (the key and what the database generates — the row version — are never written). Its row
/// version is the one the client read: a row changed since, or missing, fails the save with
/// DbUpdateConcurrencyException. A name the entity does not have is an ArgumentException.
/// </summary>
void Update(T entity, IReadOnlyCollection<string> fields);

/// <summary>
/// Marks the row with that Id to delete, without reading it, at the row version the client read: true.
/// False, nothing marked, when that version does not fit the row version's type — it was never a version
/// of this row (the client's mistake). The version is required when the entity has a row version
/// (ArgumentException without it) and ignored when it has none. The stub is built with the entity's
/// parameterless constructor. A row changed since, or missing, fails the next save with
/// DbUpdateConcurrencyException.
/// </summary>
bool TryDeleteById(int id, ulong? versionReadByClient);

/// <summary>
/// Whether the entity has a row version ([Timestamp] / IsRowVersion: a concurrency token the database
/// generates), so a client must send the version it read.
/// </summary>
bool HasRowVersion { get; }
```

```csharp
// src/Zerox.Ef/Db/Repository.cs — the implementation
public bool HasRowVersion => RowVersion() is not null;

public void Update(T entity, IReadOnlyCollection<string> fields)
{
    ArgumentNullException.ThrowIfNull(entity);
    ArgumentNullException.ThrowIfNull(fields);
    var entry = _db.Set<T>().Attach(entity);
    foreach (var name in fields)
    {
        var property = entry.Metadata.FindProperty(name)
            ?? throw new ArgumentException($"{typeof(T).Name} has no property '{name}'.", nameof(fields));
        // The key identifies the row; what the database generates is the database's.
        if (!property.IsKey() && property.ValueGenerated == ValueGenerated.Never)
            entry.Property(name).IsModified = true;
    }
}

public bool TryDeleteById(int id, ulong? versionReadByClient)
{
    var stub = Activator.CreateInstance<T>();
    stub.Id = id;
    if (RowVersion() is { } rowVersion)
    {
        if (versionReadByClient is not ulong version)
            throw new ArgumentException($"{typeof(T).Name} has a row version: give the version the client read.", nameof(versionReadByClient));
        if (!TryRowVersion(version, rowVersion.ClrType, out var value))
            return false;
        rowVersion.PropertyInfo!.SetValue(stub, value);
    }
    _db.Set<T>().Remove(stub);
    return true;
}

// IDbContext exposes no Model: the entity type comes from the set.
private IProperty? RowVersion() =>
    _db.Set<T>().EntityType.GetProperties()
        .SingleOrDefault(p => p.IsConcurrencyToken && p.ValueGenerated == ValueGenerated.OnAddOrUpdate);

// A number from the client in the row version's own type (uint, ulong or long: ApplyOptimisticLock refuses
// any other); one that does not fit was never a version of this row.
private static bool TryRowVersion(ulong version, Type type, out object value)
{
    value = version;
    if (type == typeof(uint))
    {
        if (version > uint.MaxValue)
            return false;
        value = (uint)version;
    }
    else if (type == typeof(long))
    {
        if (version > long.MaxValue)
            return false;
        value = (long)version;
    }
    return true;
}
```

[Fact]
public async Task Should_ThrowConcurrency_WhenTheVersionWasReadBeforeAMassiveUpdate()
{
    Assert.SkipUnless(TestDatabase.OnPostgres, "SQLite has no row version: the lock is proved on PostgreSQL.");
    var id = await SeedAsync("a");
    var read = (await ReadAsync(id)).Version;           // the client's GET

    await using var scope = Db.NewScope();
    var rows = scope.ServiceProvider.GetRequiredService<IRepository<Locked>>();
    rows.Update(new Locked { Id = id, Name = "mine", Version = read }, [nameof(Locked.Name)]);

    var save = () => rows.SaveChangesAsync(Ct);

    await save.Should().ThrowAsync<DbUpdateConcurrencyException>();
    (await ReadAsync(id)).Name.Should().Be("massive");
}
